# Raw Source Vocabulary — Per-Tool Reference

This file lists the verbatim Thai vocabulary captured from each of the 15 Thai e-commerce ERP/seller tools surveyed. Use it when you want to see exactly how a specific real-world brand phrased something, or to understand the tonal range of a category.

Tools are organized by category. ⭐ = full landing page captured verbatim. 🟡 = partial vocabulary (from search excerpts or meta descriptions).

## A. Order & Stock Management (ERP / OMS)

### ⭐ Zort (Zortout) — https://zortout.com/
**Category:** ERP / OMS+WMS
**Register:** Neutral / Professional
**Hero:** "ZORT ระบบจัดการร้านค้าออเดอร์ และสต๊อกออนไลน์ครบวงจร"
**Sub-hero:** "จัดการร้านค้าออนไลน์ด้วยระบบหลังบ้าน — ใช้งานง่าย ครบวงจร และมีประสิทธิภาพจาก ZORT ทั้งการจัดออเดอร์ สต๊อกสินค้า การส่งสินค้า และบัญชี"
**Primary CTA:** "ทดลองใช้งานฟรี"
**Distinctive vocabulary:**
- Section headers in English ALL CAPS + Thai sub-heading
- "ออเดอร์" + "คำสั่งซื้อ" used interchangeably
- Uses **สต๊อก** (with อ)
- "หลังบ้าน" (not หลังร้าน)
- "คุม" as action verb: "คุมสต๊อก", "คุมได้ทุกช่องทาง"
- "สินค้าจม" = dead stock (colloquial)
- "พาร์ทเนอร์ธุรกิจ"
- "ใบแปะกล่อง" = shipping label (distinctive choice)
- "Scale" kept in English even in Thai sentences
- 15-day free trial

## Cross-tool patterns reference (recap)

### CTA frequency across tools

| CTA | Tools that use it |
|---|---|
| ทดลองใช้ฟรี / ทดลองใช้งานฟรี | Zort, PEAK, Zaapi, Page365 |
| สมัครใช้งาน / สมัครเลย | Page365, Zort, BigSeller |
| เริ่มต้นใช้งาน / เริ่มใช้งานเลย | Page365 (hero), PEAK, LnwShop |
| ขอใบเสนอราคา | MyCloud, Akita/Sellsuki, Packhai |
| สาธิตการใช้งาน / Book a Demo | Zaapi, BigSeller |
| เข้าสู่ระบบ | All 15 |
| ติดต่อเรา / ติดต่อทีมงาน | All 15 |

### Free trial lengths
- 7 days: Zaapi
- 14 days: BigSeller (some plans)
- 15 days: Zort
- 30 days: PEAK
- 3 months: POSPOS
- Free forever: Page365, FillGoods, BigSeller (base plan), LnwShop (base plan)
- 1 month: DataGlass

### Stock spelling distribution
- **สต๊อก** (with อ): Zort, MyCloud, Page365 (occasionally), DataGlass (some files)
- **สต็อก** (with ต): Shipnity, PEAK, Page365 (occasionally), DataGlass (most files)
- **สต๊อค** (with อ + ค): Sellsuki/Akita

### Back-office spelling distribution
- **หลังบ้าน** (universal): Page365, Zort, MyCloud, Sellsuki/Akita, PEAK, Buzzebees, Zaapi, Oasys, BigSeller, DataGlass
- **หลังร้าน** (Shipnity only): Shipnity

### Shipping label term distribution
- **ใบจ่าหน้าพัสดุ** / **ใบจ่าหน้า** (formal/pure Thai): Page365, Oasys
- **ใบแปะกล่อง** (Zort)
- **ใบปะหน้า** (FillGoods)
