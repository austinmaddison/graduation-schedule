# English → Thai Translation Glossary

This glossary covers the wider Thai e-commerce SaaS dialect (Page365, Zort, Zaapi, Shipnity, FillGoods, BigSeller, MyCloudFulfillment, Akita/Sellsuki, LnwShop, PEAK, Buzzebees, iShip, Oasys, Packhai, POSPOS) **plus** DataGlass-specific marketing terminology.

**Important — translation philosophy:**
- **You don't have to be strict.** Modern Thai e-commerce SaaS code-switches heavily. Many English words read as more natural than their Thai equivalents to working sellers.
- **DataGlass canon wins.** If a term is in `dataglass-marketing-canon.md`, use that — don't substitute a "more Thai" alternative.
- **Brand-able terms stay English.** Shopee stays Shopee (not ช้อปปี้). ROAS stays ROAS. order can stay "order" in casual sentences.
- This glossary recommends a Thai form when one is genuinely better; otherwise it flags 🇬🇧 = keep in English.

**How to read this glossary:**
- **Bold** = the recommended translation
- (alt: X) = acceptable alternative seen in market
- *italic* = formal / academic register; avoid in marketing copy
- ⚠️ = common mistranslation to avoid
- 🇬🇧 = keep in English (do not translate)
- 🟦 = DataGlass canonical term (from `dataglass-marketing-canon.md`)
